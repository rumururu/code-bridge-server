Scripts

A shell step runs one of these — no model, no tokens, no approval prompt. Steps reference a script by name, never by command line, so registering is the moment the script is vetted. The path is checked now, not at 3am inside a scheduled run.

Unattended permissions

A scheduled run has nobody to tap "approve", so the first time it wants a terminal, a file or the browser it stops and waits — and because a schedule skips while its task is still active, every later run is skipped too. Standing rules below let named operations through without prompting. Grant the narrowest scope that works.
